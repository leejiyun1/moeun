# Review Taste Learning Design

## 문서 목적

이 문서는 리뷰 작성 흐름과 입맛 학습 방향을 정의한다.

현재 확정 기준은 아래다.

- 사용자는 전체 평점과 후기만 남긴다.
- 사용자는 신뢰도, 맛 평가, 입맛 적합도, 태그를 직접 입력하지 않는다.
- 리뷰 저장만으로 입맛 프로필을 자동 변경하지 않는다.
- 리뷰 기반 입맛 학습은 후기 텍스트 분석을 별도 단계로 설계한 뒤 붙인다.

## 결정 배경

사람이 직접 입력하는 세부 평가는 부정확할 가능성이 높다.

제거한 입력:

- 신뢰도
- 단맛/산미/바디감/탄산감/쓴맛/향 점수
- 입맛 적합도 점수
- 좋았던 점/아쉬웠던 점 태그

이유:

- 사용자가 맛을 정확히 분리해서 평가하기 어렵다.
- 입력 부담이 커지면 리뷰 작성률이 떨어진다.
- 부정확한 세부 점수는 추천 품질을 오히려 낮출 수 있다.
- 평점과 후기 텍스트만 받아도 사용 경험은 단순하게 유지된다.

## 현재 리뷰 입력

필수:

- 전체 평점
- 후기 텍스트

선택:

- 이미지

API 요청:

```json
{
  "order_item": 1,
  "rating": 5,
  "comment": "달달하고 향이 좋아서 마시기 편했어요."
}
```

## 데이터 모델 기준

현재 원본 모델은 `Feedback`이다.

유지 필드:

- `rating`: 전체 만족도
- `comment`: 후기 텍스트
- `image_url`: 후기 이미지
- `view_count`: 후기 조회수
- `created_at`, `updated_at`

제거한 필드:

- `sweetness`
- `acidity`
- `body`
- `carbonation`
- `bitterness`
- `aroma`
- `confidence`
- `selected_tags`

## 처리 흐름

### 1. 리뷰 저장

```text
사용자 리뷰 작성
→ Feedback 저장
→ 이미지가 있으면 업로드
→ 상품 review_count 증가
```

주의:

- 리뷰 저장은 입맛 프로필을 직접 변경하지 않는다.
- 현재 `Feedback.save()`에 남아 있는 상품 리뷰 수 증가는 다음 리팩터링에서 `FeedbackCommandService`로 이동한다.

### 2. 입맛 학습

현재 상태:

- 리뷰 기반 입맛 학습은 비활성화한다.
- 취향 프로필은 취향 테스트 결과를 기준으로 유지한다.

다음 설계 방향:

```text
Feedback
→ 후기 텍스트 분석
→ 신뢰 가능한 맛 선호 신호 추출
→ TasteProfileLearningService
→ PreferTasteProfile 소폭 갱신
```

전제:

- 분석 실패가 리뷰 저장 실패로 이어지면 안 된다.
- 분석 결과는 원본 리뷰와 분리해서 저장한다.
- 확실하지 않은 분석은 입맛 프로필에 반영하지 않는다.

## 프론트 화면 기준

리뷰 작성 UI:

```text
전체 평점
후기
이미지
```

사용자에게 보여줄 문구:

```text
제품이 취향에 맞으셨나요?
시음 후기를 남겨주세요.
```

피해야 할 문구:

```text
단맛 점수를 입력해주세요
입맛 적합도를 선택해주세요
신뢰도를 입력해주세요
좋았던 점/아쉬웠던 점을 선택해주세요
```

## 구현 단계

### 1단계

상태: 진행 중

- 프론트 리뷰 작성 화면에서 세부 평가 UI 제거
- 프론트 요청에서 평점/후기/이미지만 전송
- 백엔드 `Feedback` 세부 평가 필드 제거
- 리뷰 저장 시 취향 프로필 자동 갱신 제거
- 문서 기준을 단순 리뷰 입력으로 정리

### 2단계

상태: 예정

- `FeedbackCommandService` 추가
- `Feedback.save()` side effect 제거
- 리뷰 저장, 이미지 저장, 상품 통계 변경을 transaction으로 묶기

### 3단계

상태: 예정

- 후기 텍스트 분석 설계
- 로컬 LLM 또는 규칙 기반 분석 인터페이스 정의
- 분석 결과 저장 모델 설계

### 4단계

상태: 예정

- `TasteProfileLearningService` 추가
- 확실한 분석 결과만 취향 프로필에 소폭 반영
- 반영 이력 저장
